# Сервер UniFlow

Сервер задач для Android-приложения UniFlow. Написан на Kotlin с Ktor и хранит данные в SQLite через Exposed.

## Запуск

Нужен JDK 21. Gradle 9.5.1 запускается через wrapper из этой папки.

Windows PowerShell:

```powershell
.\gradlew.bat run
```

Linux и macOS:

```bash
./gradlew run
```

Сервер слушает `127.0.0.1:8080`. Проверить запуск можно запросом `GET http://127.0.0.1:8080/`. В стандартном Android-эмуляторе этот адрес доступен как `http://10.0.2.2:8080`.

При первом запуске сервер создаёт таблицу задач в файле `uniflow.db` в рабочей папке. Чтобы выбрать другой файл, перед запуском задайте переменную окружения `UNIFLOW_DB_PATH`. Указанная папка должна существовать.

Если в файле есть таблица из ранней версии UniFlow с полем `id INT PRIMARY KEY`, сервер обновит её схему в одной транзакции и сохранит существующие задачи и их ID.

Чтобы изменить адрес или порт, передайте параметры Ktor. Например, `./gradlew run --args="-host=127.0.0.1 -port=8081"`.

## API задач

| Запрос | Результат |
| --- | --- |
| `GET /tasks` | `200 OK` и массив задач |
| `POST /tasks` | `201 Created` и задача с назначенным сервером ID |
| `PUT /tasks/{id}` | `200 OK` и обновлённая задача |
| `DELETE /tasks/{id}` | `200 OK` и текст `Задача удалена` |

Тело `POST` и `PUT` передаётся как `application/json`. Сервер убирает пробелы по краям текстовых полей. Поля `subject` и `title` обязательны и ограничены 100 и 200 символами. Поле `deadline` может быть пустым и ограничено 100 символами. Поле `isCompleted` принимает `true` или `false`. При создании значение по умолчанию — `false`, а ID назначает сервер. При обновлении `id` в теле должен совпадать с положительным целым ID в URL. Некорректные данные возвращают `400 Bad Request`. Обновление или удаление отсутствующей задачи возвращает `404 Not Found`.

Пример запроса на создание находится в [requests.http](requests.http).

## API для Telegram-бота

`POST /telegram/tasks` принимает JSON с полями `updateId` (неотрицательное целое число) и `task` (те же поля, что у `POST /tasks`). Передайте общий секрет из `UNIFLOW_BOT_SECRET` в заголовке `X-Bot-Secret`. При неверном или отсутствующем секрете сервер возвращает `403 Forbidden`.

Сервер сохраняет задачу и событие Telegram в одной транзакции. Повтор с тем же `updateId` и теми же нормализованными полями возвращает `201 Created` и исходную задачу с тем же ID. Если этот `updateId` уже использован с другими данными, сервер возвращает `409 Conflict`.

## Тесты

`./gradlew test` или `.\gradlew.bat test` проверяет запуск API, создание, чтение, обновление и удаление задач, ответы на ошибочные запросы и повторную доставку Telegram-событий. Тесты используют временные файлы SQLite.
